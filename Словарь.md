# Словарь

← [[🗺️ Foray — Карта проекта]]

## Назначение

Персональный словарный блокнот пользователя. Доступен на `dict.lllang.site`. Все операции **закрыты подпиской** ([[Подписки и Платежи]]).

## Структура слова

```json
{
  "word": "serendipity",
  "translation": "счастливая случайность",
  "part_of_speech": "noun",
  "context": "I found this cafe by serendipity.",
  "audio": "<base64 или URL>",
  "is_public": true
}
```

## API эндпоинты

| Метод | Путь | Доступ | Назначение |
|-------|------|--------|------------|
| GET | `/api/dict/words` | Бесплатно | Получить свои слова |
| POST | `/api/dict/words` | Подписка | Добавить слово |
| PUT | `/api/dict/words` | Подписка | Редактировать слово |
| DELETE | `/api/dict/words` | Подписка | Удалить слово |
| GET | `/api/dict/words/search` | Подписка | Поиск (свои + публичные) |
| GET | `/api/dict/stats` | Бесплатно | Статистика изучения |

## Поиск

`GET /api/dict/words/search?query=...` одновременно ищет:
1. В **личных словах** пользователя
2. В **публичных словах** сообщества (`is_public: true`)

## Функция записи голоса

Фронтенд использует **Web MediaRecorder API** для записи произношения слова. Аудио прикрепляется к карточке слова.

## UI (фронтенд)

- 4 вкладки в виде закладок книги: **Добавить / Поиск / Все слова / Статистика**
- Карточки слов с алфавитной навигацией
- Нет фреймворка — Vanilla JS
