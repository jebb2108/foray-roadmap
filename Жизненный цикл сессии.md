# Жизненный цикл сессии

← [[🗺️ Foray — Карта проекта]] | Связан: [[WebSocket Чат]], [[Матчмейкинг]]

## Полный флоу сессии

```
[МАТЧ НАЙДЕН]
    ↓
Оба пользователя подключаются по WebSocket
    ↓
Сервер отправляет: match_info (данные партнёра)
    ↓
┌─────────────────────────────────────────┐
│         ФАЗА ПОДТВЕРЖДЕНИЯ (60 сек)      │
│                                         │
│  Пользователь A ──[confirm]──► сервер   │
│  Пользователь B ──[confirm]──► сервер   │
│                                         │
│  Если один нажал cancel → session_ended  │
│  Если истёк таймер → timeout → ended    │
└─────────────────────────────────────────┘
    ↓ оба подтвердили
[SESSION_STARTED] broadcast с expires_at
    ↓
┌─────────────────────────────────────────┐
│           АКТИВНАЯ СЕССИЯ (15 мин)       │
│                                         │
│  Обмен сообщениями через WebSocket      │
│  Typing indicators                      │
│  Таймер обратного отсчёта на экране     │
└─────────────────────────────────────────┘
    ↓ таймер истёк или пользователь вышел
[SESSION_ENDED] broadcast
    ↓
┌─────────────────────────────────────────┐
│        ПОСТ-СЕССИЯ                      │
│                                         │
│  Предложение добавить партнёра в друзья │
└─────────────────────────────────────────┘
```

## State машина подтверждения

Обрабатывается в `handle_state_message()`:

| Событие | Условие | Результат |
|---------|---------|-----------|
| `confirm` | Только один готов | Ждём второго |
| `confirm` | Оба готовы | `session_started` |
| `cancel` | Любой | `session_ended` |
| `timeout` | Любой | `session_ended` |

## Данные партнёра (match_info)

```json
{
  "nickname": "...",
  "age": 23,
  "gender": "male",
  "topics": ["travel", "tech"],
  "intro": "Hi! I want to practice..."
}
```

Данные берутся из JWT токена при подключении к WebSocket.

## Для Foray: изменения

| Аспект               | Сейчас                  | Foray                        |
| -------------------- | ----------------------- | ---------------------------- |
| Пост-сессия          | Обмен контактами (веб)  | In-app запрос дружбы         |
| Таймер подтверждения | 60 сек                  | 60 сек + push-уведомление    |
| После сессии         | Только обмен контактами | Рейтинг партнёра + заметки   |
