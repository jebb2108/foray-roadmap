## 🏗️ Архитектура: До и После

### ДО (chat.lllang.site)

```
Web Client → web-app-service (монолит) → Gateway
              ↓
         ├─ In-memory WebSocket state
         ├─ JWT manager
         ├─ Email service
         └─ Nginx proxy
```

**Проблемы:**
- ❌ Нет горизонтального масштабирования
- ❌ In-memory state теряется при рестарте
- ❌ Polling матчмейкинга (неэффективно)
- ❌ Нет собственной системы аккаунтов
- ❌ Монолитная структура

### ПОСЛЕ (Foray)

```
Mobile Client → API Gateway (Kong)
                ├─ Load balancing
                ├─ Rate limiting
                ├─ JWT validation
                └─ Request routing
                ↓
            Микросервисы (6 сервисов):
            ├─ Auth Service (3001)
            ├─ Messaging Service (3002)
            ├─ Matchmaking Service (3003)
            ├─ Rating Service (3004)
            ├─ Notification Service (shared)
            └─ WebSocket Service (3005)
                ↓
            Shared Infrastructure:
            ├─ PostgreSQL (primary store)
            ├─ Redis (cache, queues)
            ├─ RabbitMQ (event broker)
            ├─ Elasticsearch (full-text search)
            └─ MinIO (object storage)
```

**Преимущества:**
- ✅ Микросервисная архитектура
- ✅ Независимое масштабирование
- ✅ Redis для распределённого состояния
- ✅ Push notifications вместо polling
- ✅ Event-driven система (RabbitMQ)
- ✅ Горизонтальное масштабирование
- ✅ Собственная система аккаунтов

### 🔄 Переработуем

| Компонент | Было | Станет | Причина |
|-----------|------|--------|---------|
| **Платформа** | Веб | Мобильное (iOS/Android) | Новый продукт |
| **Auth система** | Веб-сессия (IP + cookie) | Email + пароль + JWT + refresh token | Собственные аккаунты |
| **Notifications** | Polling каждую секунду | Push (FCM/APNs) | Мобильная эффективность |
| **WebSocket state** | In-memory Dict | Redis (хранилище с persistence) | Масштабируемость |
| **Architecture** | Монолит web-app-service | Микросервисы (6 независимых) | Гибкость и масштабируемость |
| **Database** | Монолитная БД | Shared PostgreSQL + Cache layer (Redis) | Оптимизация по сервисам |
| **Message Broker** | Нет | RabbitMQ | Event-driven система |
| **Search** | Нет | Elasticsearch | Full-text поиск сообщений |
| **File Storage** | Нет | MinIO/S3 | Управление медиа-контентом |

| **Profile enrichment** | AI рекомендации партнёров | Matchmaking Service |
| **Offline режим** | Локальное кэширование сообщений | Mobile App |
| **Multiple payment methods** | Apple Pay + Google Pay (+ YooKassa) | Payment Service |
| **Moderation system** | Флаги, shadow ban, report handling | Rating Service |
| **Multi-instance deployment** | Load balancing, auto-scaling | API Gateway + Kong |
| **Distributed tracing** | Jaeger/Zipkin для отладки | API Gateway |
| **Comprehensive logging** | ELK Stack (Elasticsearch, Logstash, Kibana) | Infrastructure |

## 📋 Микросервисы Foray (Новые 6 сервисов)

### 1. **Auth Service** (Port 3001)

```
Функции:
├─ Регистрация пользователей
├─ Login / logout
├─ Email верификация
├─ JWT токены (access + refresh)
├─ Password reset
└─ Profile management

Использует:
├─ PostgreSQL (users table)
├─ Redis (blacklist, cache)
└─ Resend (email service)
```

### 2. **Messaging Service** (Port 3002)

```
Функции:
├─ WebSocket чат (реальное время)
├─ REST API для истории
├─ Шифрование Fernet
├─ Upload медиа (S3/MinIO)
├─ Full-text поиск
└─ Read receipts

Использует:
├─ PostgreSQL (messages table)
├─ Redis (active connections)
├─ Elasticsearch (search)
└─ MinIO/S3 (files)
```

### 3. **Matchmaking Service** (Port 3003)

```
Функции:
├─ Управление очередью
├─ Алгоритм подбора пар
├─ Создание матчей
├─ Queue status API
└─ Match history

Использует:
├─ PostgreSQL (matches table)
├─ Redis (queue as sorted set)
└─ RabbitMQ (match events)
```

### 4. **Rating Service** (Port 3004)

```
Функции:
├─ Приём оценок (1-5 звёзд)
├─ Расчёт avg rating
├─ Report users
├─ Moderation rules
└─ Shadow ban logic

Использует:
└─ PostgreSQL (ratings, flags table)
```

### 5. **Notification Service** (Shared)

```
Функции:
├─ Register FCM/APNs tokens
├─ Send push notifications
├─ Email notifications
├─ In-app notifications
└─ Notification history

Использует:
├─ PostgreSQL (push_tokens table)
├─ FCM (Android)
├─ APNs (iOS)
└─ Resend (email)
```

### 6. **WebSocket Service** (Port 3005)

```
Функции:
├─ Manage WebSocket connections
├─ Real-time events (Socket.io)
├─ Room management
├─ User presence tracking
└─ Session state

Использует:
├─ Redis (session store + adapter for Socket.io)
└─ RabbitMQ (event pubsub)
```

## 🔌 API Gateway (Kong)

```
Входная точка всех запросов:

├─ TLS/SSL termination
├─ JWT validation
├─ Rate limiting
├─ Request validation (OpenAPI)
├─ Request logging (ELK)
├─ Distributed tracing (Jaeger)
├─ Metrics collection (Prometheus)
└─ CORS handling

Routing:
├─ /auth/*        → Auth Service (3001)
├─ /messages/*    → Messaging Service (3002)
├─ /queue/*       → Matchmaking Service (3003)
├─ /ratings/*     → Rating Service (3004)
├─ /notifications/* → Notification Service
└─ /ws/*          → WebSocket Service (3005)
```

## 🚀 Развёртывание

### Стек технологий

| Layer | Технология | Версия | Причина |
|-------|-----------|--------|---------|
| **API Gateway** | Kong | 3.x | Industry standard, Rich plugin ecosystem |
| **Microservices** | FastAPI / Node.js | Latest | High performance, async |
| **Database** | PostgreSQL | 15+ | Reliable, Rich features |
| **Cache** | Redis | 7+ | Fast in-memory store |
| **Message Broker** | RabbitMQ | 3.12+ | Reliable, AMQP protocol |
| **Search** | Elasticsearch | 8.x | Full-text search, Analytics |
| **File Storage** | MinIO | Latest | Self-hosted S3 alternative |
| **Containerization** | Docker | Latest | Portable, Reproducible |
| **Orchestration** | Kubernetes | 1.27+ | Production-grade scaling |

### Docker Compose (Локальная разработка)

Файл: `docker-compose.yml` в корне проекта

Запуск:
```bash
docker-compose up -d
```

Запущенные сервисы:
- Kong Gateway: http://localhost:8000
- Auth Service: http://localhost:3001
- Messaging Service: http://localhost:3002
- Matchmaking Service: http://localhost:3003
- Rating Service: http://localhost:3004
- WebSocket Service: http://localhost:3005
- PostgreSQL: localhost:5432
- Redis: localhost:6379
- RabbitMQ: localhost:5672 (amqp), 15672 (management)
- Elasticsearch: http://localhost:9200
- MinIO: http://localhost:9000
