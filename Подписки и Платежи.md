# Подписки и Платежи

← [[🗺️ Foray — Карта проекта]]

## Модель монетизации

Freemium с подпиской. Без подписки пользователь может зарегистрироваться и смотреть статистику словаря. Всё остальное — за подпиской.

## Что закрыто подпиской

- Участие в [[Матчмейкинг|матчмейкинге]] (войти в очередь)
- CRUD операции [[Словарь|словаря]]
- Поиск по публичным словам

## Провайдер платежей

**YooKassa** (российский аналог Stripe).

## Флоу платежа

```
Пользователь оформляет подписку (в Telegram боте или внешнем интерфейсе)
    ↓
YooKassa отправляет webhook
    ↓
POST /api/payments/webhook/yookassa
    ↓ (этот сервис просто проксирует)
Gateway /api/payments/... обрабатывает и сохраняет дату окончания
```

## Проверка подписки

```python
# В матчмейкинге и словаре перед каждой операцией:
response = await gateway.get(f"/api/payments/due_to?user_id={user_id}")
due_to = response.json()["until"]

if datetime.fromisoformat(due_to) < datetime.now():
    raise HTTPException(status_code=403, detail="Subscription expired")
```

Данные хранятся в [[Gateway Сервис|Gateway]], не в этом сервисе.

## FAILSAFE

В конфиге есть переменная `FAILSAFE=Q1RN7DBF8F8QTPEA86ZUJSWL`. Помечена как «personal use» — вероятно, код для ручного обхода проверки подписки в отладочных целях.

## Для Foray: изменения

| Провайдер | YooKassa | YooKassa + Apple Pay / Google Pay |
