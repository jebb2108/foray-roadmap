# Подписки и Платежи

← [[🗺️ Foray — Карта проекта (Обновлено)]]

## Модель монетизации

Freemium с подпиской. Без подписки пользователь может зарегистрироваться и просматривать профиль. Всё остальное — за подпиской.

## Что закрыто подпиской

- Участие в [[Матчмейкинг|матчмейкинге]] (войти в очередь)

## Провайдер платежей

**YooKassa** (российский аналог Stripe).

## Флоу платежа

```
Пользователь оформляет подписку в приложении
    ↓
YooKassa отправляет webhook
    ↓
POST /api/payments/webhook/yookassa
    ↓ (проксируется в Gateway)
Gateway обрабатывает и сохраняет дату окончания
```

## Проверка подписки

```python
response = await gateway.get(f"/api/payments/due_to?user_id={user_id}")
due_to = response.json()["until"]

if datetime.fromisoformat(due_to) < datetime.now():
    raise HTTPException(status_code=403, detail="Subscription expired")
```

## Для Foray: изменения

| Аспект | Было | Станет |
|--------|------|--------|
| Провайдер | YooKassa (веб) | YooKassa + Apple Pay + Google Pay |
| Управление подпиской | Веб-страница | In-app экран подписки |
| Trial-период | Не указан | Рекомендуется 7-дневный trial |
| Webhook | Проброс в Gateway | То же + валидация HMAC подписи |
