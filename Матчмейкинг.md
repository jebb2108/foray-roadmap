# Матчмейкинг

← [[🗺️ Foray — Карта проекта (Обновлено)]]

## Общий флоу

```
Пользователь нажимает "войти в очередь"
    ↓
POST /api/worker/match/toggle
    ↓ проверка подписки
    ↓ проксируется в Gateway Worker
Пользователь в очереди
    ↓
Polling / Push:
  GET /api/worker/check_match?user_id=
  GET /api/worker/queue/status
    ↓ матч найден
Gateway возвращает { match_id, room_id }
    ↓
Клиент вызывает GET /api/user/create_token
    ↓
Переход в экран чата с JWT
```

## Визуальная логика зала ожидания

| Кол-во в очереди | Состояние |
|-----------------|-----------|
| 0 | Пустая комната |
| 1–4 | Полупустая комната |
| 5+ | Полная комната |

## API эндпоинты

| Метод | Путь | Назначение |
|-------|------|------------|
| POST | `/api/worker/match/toggle` | Войти/выйти из очереди |
| GET | `/api/worker/check_match` | Проверить наличие матча |
| GET | `/api/worker/queue/status` | Размер очереди |
| GET | `/api/worker/queue/{user_id}/status` | Статус конкретного пользователя |
| PUT | `/api/worker/cancel_match` | Отменить матч |

## Где живёт алгоритм подбора

Алгоритм подбора — в [[Gateway Сервис|Gateway]] (Worker-сервис). Этот сервис только проксирует запросы.

## Защита

Перед добавлением в очередь проверяется активная [[Подписки и Платежи|подписка]]:
```python
due_to = await gateway.get_subscription_due_to(user_id)
if datetime.fromisoformat(due_to) < datetime.now():
    raise HTTPException(403)
```

## Для Foray: что улучшить

- **Заменить polling на Push Notifications** (FCM / APNs) — сервер сам уведомит о матче
- **WebSocket для очереди** вместо polling каждую секунду (экономия батареи)
- Визуализация очереди — анимация вместо статичных картинок
