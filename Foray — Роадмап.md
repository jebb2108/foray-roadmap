# Foray — Роадмап

← [[🗺️ Foray — Карта проекта]]

## Принцип

Двигаться от минимального рабочего продукта к полному. Каждая фаза — полноценный, запускаемый продукт.

---

## Фаза 1 — MVP (ядро)

**Цель:** воспроизвести главный флоу chat.lllang.site без Telegram.

| Задача | Зависимость | Сложность |
|--------|-------------|-----------|
| Регистрация + email верификация | [[Foray — Аутентификация]] | Средняя |
| Логин (email + пароль) | [[Foray — Аутентификация]] | Низкая |
| Профиль (ник, возраст, пол, интересы, интро) | [[Аутентификация — Telegram]] | Низкая |
| Зал ожидания с очередью | [[Матчмейкинг]] | Средняя |
| Матчмейкинг (войти/выйти из очереди) | [[Матчмейкинг]] | Низкая |
| WebSocket чат с тайм-лимитом | [[WebSocket Чат]] | Высокая |
| Подтверждение матча (Accept/Decline) | [[Жизненный цикл сессии]] | Средняя |
| Базовые push-уведомления (матч найден) | [[Foray — Технический стек]] | Средняя |

---

## Фаза 3 — Улучшения UX

**Цель:** нативный мобильный опыт, выходящий за рамки веба.

| Задача | Описание |
|--------|----------|
| Обмен контактами (in-app) | Вместо Telegram-контактов — in-app запрос дружбы или share телефона |
| Настройка длительности сессии | 15 / 30 / 45 мин |
| Рейтинг партнёра | После сессии: ⭐⭐⭐⭐⭐ |
| Полные push-уведомления | Все события: typing, partner_status, session_ended |
| Onboarding | Объяснение концепции новым пользователям |
| Темы сессии | Фильтр матчмейкинга по интересам |

---

## Фаза 4 — AI и Community

**Цель:** использовать задатки AI-сервиса в Gateway.

| Задача | Описание |
|--------|----------|
| Слово из чата → словарь | Тап на слово в истории → сохранить |
| AI-объяснение слов | Объяснение + примеры от модели |
| SRS повторения | Интервальные повторения (Anki-style) |
| Топик-карточки | Готовые темы для разговора на экране сессии |
| Лента активности сообщества | Публичные слова + активность |

## Изменения в [[Gateway Сервис|Gateway]] по фазам

### Фаза 1
- [ ] `POST /api/auth/register`
- [ ] `POST /api/auth/login`
- [ ] `POST /api/auth/refresh`
- [ ] `GET /api/auth/verify`
- [ ] `POST /api/push/token` — сохранить FCM/APNs токен
- [ ] Обновить WebSocket auth на access-токен

### Фаза 2
- [ ] Интеграция Apple Pay / Google Pay в платёжный сервис
- [ ] `POST /api/auth/link-telegram` — опциональная привязка Telegram

### Фаза 3+
- [ ] `POST /api/sessions/{id}/rating` — оценка партнёра
- [ ] Redis для WebSocket state (горизонтальное масштабирование)
