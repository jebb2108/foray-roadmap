# 🗺️ Foray — Карта проекта

Foray — мобильное приложение для парных разговорных сессий на английском языке. Наследует все функции [[Архитектура chat.lllang.site|chat.lllang.site]], но работает независимо от Telegram.

## Ключевой принцип

> Foray = все фичи chat.lllang.site + нативный мобильный опыт + собственная система аккаунтов.
> Telegram остаётся опциональным каналом уведомлений, но не является обязательным для входа.
