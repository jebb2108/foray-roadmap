# 🗺️ Foray — Карта проекта

**Foray** — мобильное приложение для поиска единомышленников через текстовый чат на основе общих интересов.

---

## Архитектура (кратко)

```
┌──────────────────────────────────────────┐
│              КЛИЕНТ                       │
│     React Native  (iOS + Android)         │
│                                           │
│  Auth · Queue · Chat · Profile · Settings  │
└─────────────────┬────────────────────────┘
                  │ HTTPS + WSS
                  ▼
┌──────────────────────────────────────────┐
│              СЕРВЕР                       │
│                                           │
│  ┌──────────────────────────────────┐    │
│  │  Gateway  (Nginx + FastAPI)      │    │
│  └──┬──────────┬────────┬───────┬──┘    │
│     ▼          ▼        ▼       ▼        │
│  Auth       Core     Chat   Payment      │
│  :3001      :3002    :3003   :3004       │
│                                           │
│  PostgreSQL · Redis · S3/MinIO            │
│  Resend · FCM/APNs · YooKassa            │
└──────────────────────────────────────────┘
```

## Роадмап

```
Фаза 1 — Foundation
  ├─ Gateway + Auth Service
  ├─ PostgreSQL схемы
  └─ Docker Compose окружение

Фаза 2 — Core
  ├─ Core Service (профили, интересы)
  ├─ Матчмейкинг воркер
  └─ Push-уведомления (FCM/APNs)

Фаза 3 — Chat
  ├─ WebSocket-чат
  ├─ История сообщений
  └─ Загрузка медиафайлов (S3/MinIO)

Фаза 4 — Polish
  ├─ Payment Service (YooKassa)
  └─ Модерация

Фаза 5 — Mobile
  ├─ React Native (Expo)
  ├─ iOS + Android
  └─ Beta-тест

Фаза 6 — Production
  ├─ Security audit
  ├─ Load testing
  └─ Launch
```
