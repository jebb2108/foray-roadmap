# Foray — Интерфейс и UX

← [[🗺️ Foray — Карта проекта]]

---

## Концепция

Foray — русское "foray" намекает, но название восходит к латинскому: **червоточина** как метафора. Незнакомые люди, разделённые пространством интересов, находят друг друга через алгоритм — как через wormhole. Дизайн это отражает: тёмный космос, минимум элементов, одна точка притяжения.

**Три правила дизайна:**
- Ничего лишнего на экране
- Тёмная тема, никогда светлой
- Анимации говорят, текст молчит там, где это возможно

### Типографика

Inter (или SF Pro на iOS / Roboto на Android). Только два размера на экран — крупнее просить не надо.

### Аватар по умолчанию

Генерируется по `user_id` — уникальный для каждого, но абстрактный: геометрический глиф космической темы (планета, созвездие, сигнал). Не показывает лицо. **Своё реальное фото видит только сам пользователь и те, кому оно раскрыто.**

### Фоновые частицы

На всех экранах — тонкое поле из мелких точек (`opacity: 0.15–0.25`), медленно дрейфуют. Почти незаметно, но создаёт ощущение пространства. Не мешает контенту.

## Навигация

```
   ┌─────────┐               ┌──────────────────────┐
   │ Профиль │◄──── центр ───►│ Чаты с друзьями      │◄───свайп влево──► Зал ожидания
   └─────────┘   свайп вправо │ + Активный чат сверху│                   / Активный чат
                              └──────────────────────┘
```

Три экрана, горизонтальный свайп. Внизу три точки-индикатора — единственный навигационный элемент. Никакого tab bar, никаких иконок снизу.

- **Свайп вправо** → Профиль
- **Центр** → Список друзей. Если идёт активная сессия — она закреплена сверху
- **Свайп влево** → Зал ожидания. Когда матч найден и подтверждён — этот же экран становится активным чатом

Переход между экранами — лёгкий parallax: фоновые частицы движутся медленнее контента, создавая глубину.

## Экран: Чаты с друзьями (центральный)

Открывается при запуске. Показывает только друзей — людей, с которыми был взаимный запрос после сессии. Если в данный момент идёт активная матч-сессия — она закреплена отдельной карточкой сверху.

```
┌───────────────────────────────────┐
│  Foray                    ···     │  ← настройки только здесь
├───────────────────────────────────┤
│                                   │
│  ┌─────────────────────────────┐  │
│  │ ░ Активная сессия   ⏱ 11:42│  │  ← закреплённая карточка
│  │   Привет, как дела?         │  │    индиго-рамка, пульсирует
│  │                     → →     │  │    нажатие = свайп влево
│  └─────────────────────────────┘  │    (переход на экран чата)
│                                   │
│  ─────────── Друзья ─────────── │
│                                   │
│  ┌─────────────────────────────┐  │
│  │  [фото]  @friend_name       │  │  ← только добавленные друзья
│  │          хорошо, ты?        │  │    фото всегда раскрыто
│  │                      вчера  │  │
│  └─────────────────────────────┘  │
│                                   │
│  ┌─────────────────────────────┐  │
│  │  [фото]  @another_friend    │  │
│  │          до завтра!         │  │
│  │                   3 дня     │  │
│  └─────────────────────────────┘  │
│                                   │
│            ·  ●  ·               │
└───────────────────────────────────┘
```

**Детали:**
- Здесь только друзья — переписка с ними свободная, без таймера
- Если активной сессии нет — закреплённой карточки нет, список начинается с друзей
- Сессии без взаимного добавления в друзья в этот список не попадают
- Нет кнопки «новый чат» — общение только через матчмейкинг или с уже добавленными друзьями

## Экран: Зал ожидания → Активный чат (свайп влево)

Этот экран живёт в двух состояниях: **зал ожидания** (до матча) и **активный чат** (после подтверждения). Переход между ними происходит на месте — один и тот же экран, без переключения.

**Зал ожидания.** Центральный элемент — маленький сюрреалистичный домик: физический, слегка ненастоящий, как будто из другого масштаба. Большие окна, внутри — диваны. За окнами мерцают полупрозрачные силуэты людей, которые живут своей жизнью и не замечают нас. Их количество отражает размер очереди.

Фон экрана — тёмный, почти чёрный. Домик расположен в центре, немного ниже середины. Никаких других элементов окружения — просто домик в пустоте.

### Состояние 2 — В очереди (домик с людьми)

Силуэты появляются постепенно по мере роста очереди. Максимум — 5–6 фигур, после этого они просто становятся чуть плотнее. Силуэты очень блеклые (`opacity: 0.15–0.25`), едва различимы — как будто люди за матовым стеклом световые годы отсюда. Они медленно двигаются: кто-то сидит и не шевелится, кто-то прохаживается, кто-то как будто разговаривает с другим. Движения случайные, петляющие, никогда не смотрят в сторону наблюдателя.

```
┌───────────────────────────────────┐
│                                   │
│                                   │
│          ╱▔▔▔▔▔▔▔▔▔▔▔╲           │
│         ▕             ▏           │
│         ├──────────────┤          │
│         │ ┌────┐ ┌────┐│          │
│         │ │░╻ ░│ │░╻╻░││          │  ← силуэты за стеклом
│         │ │░╽ ░│ │░╽╽░││          │    блеклые, мерцают
│         │ └────┘ └────┘│          │
│         │    ┌────┐    │          │
│         │    │ ██ │    │          │  ← дверь закрыта
│         └────┴────┴────┘          │
│                                   │
│          Ищем... 4 рядом          │
│                                   │
│   ┌───────────────────────────┐   │
│   │           Выйти            │   │
│   └───────────────────────────┘   │
└───────────────────────────────────┘
```

**Детали силуэтов:**
- Анимация мерцания: случайный `opacity` между 0.10 и 0.30, медленно
- Каждый силуэт — автономный: петлевая анимация перемещения по своей траектории
- Они не реагируют на нажатия, на время, на пользователя
- За одним окном — диван, за другим — пространство для ходьбы

### Состояние 3 — Матч найден

Все силуэты медленно гаснут — `opacity` к нулю за 1.5 секунды. Окна темнеют. Домик на секунду замирает совершенно пустым и тихим.

Потом дверь открывается.

Из дверного проёма — белое сияние. Не анимированное, не пульсирующее. Просто ровный, тихий, очень яркий свет. Контраст с тёмным домиком и тёмным фоном делает его значимым.

```
┌───────────────────────────────────┐
│                                   │
│                                   │
│          ╱▔▔▔▔▔▔▔▔▔▔▔╲           │
│         ▕             ▏           │
│         ├──────────────┤          │
│         │ ┌────┐ ┌────┐│          │
│         │ │    │ │    ││          │  ← окна тёмные
│         │ │    │ │    ││          │    никого нет
│         │ └────┘ └────┘│          │
│         │   ┌──────┐   │          │
│   ░░░░░░│░░░│██████│░░░│░░░░░░    │  ← дверь открыта
│   ░░░░░ │   │      │   │ ░░░░░    │    белый свет наружу
│         └───┴──────┴───┘          │    рассеивается на землю
│                                   │
│                                   │
│   ┌──────────────────────────┐    │
│   │  Интересы: музыка, кино  │    │  ← карточка всплывает снизу
│   └──────────────────────────┘    │
│   ╔══════════╗  ╔════════════╗    │
│   ║   Войти   ║  ║ Пропустить ║   │
│   ╚══════════╝  ╚════════════╝    │
│              ⏱ 0:52              │
└───────────────────────────────────┘
```

**Детали момента:**
- Пауза ~1 сек между исчезновением силуэтов и открытием двери — тишина важна
- Свет не мигает, не пульсирует — просто есть. Это единственное приглашение
- Карточка с интересами партнёра появляется снизу через bottom sheet — имя и фото скрыты
- Кнопка «Войти» → zoom forward через дверной проём, белая вспышка → экран переходит в активный чат
- «Пропустить» или таймер истёк → дверь медленно закрывается, силуэты возвращаются, поиск продолжается
- Если партнёр пропустил — дверь закрывается, уведомление: «Не ответили — ищем дальше»

### Состояние 4 — Активный чат (тот же экран)

После нажатия «Войти» домик исчезает — экран полностью переходит в чат. Это всё ещё свайп влево, не новый экран.

```
┌───────────────────────────────────┐
│  ⬡  @unknown          ⏱ 14:51   │  ← геоглиф, никнейм, таймер сессии
│     музыка · IT · кино            │    интересы под именем
├───────────────────────────────────┤
│                                   │
│                   Привет!  00:00  │
│                              ✓✓   │
│                                   │
│  Привет, как дела?         00:14  │
│  ✓✓                               │
│                                   │
│               Хорошо, ты?  00:31  │
│                              ✓✓   │
│                                   │
│  ✏ печатает...                    │
│                                   │
├───────────────────────────────────┤
│  Сообщение...              [ ➤ ] │
└───────────────────────────────────┘
```

**Таймер** (`⏱ 14:51`) — обратный отсчёт от 15:00 до 00:00. Всегда виден в шапке. За 2 минуты до конца становится акцентным (индиго).

**Только текст** — никаких вложений, камеры, медиа.

**Параллельно на центральном экране** появляется закреплённая карточка активной сессии с тем же таймером.

---

### На 10-й минуте — попап раскрытия

Появляется у обоих одновременно. Чат не блокируется, можно продолжать печатать поверх.

```
╭───────────────────────────────────╮
│                                   │
│      ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~        │  ← шиммер
│                                   │
│   Вы уже 10 минут разговариваете  │
│                                   │
│   Раскрыть личность и фото        │
│   друг друга?                     │
│                                   │
│   ┌──────────────┐ ┌───────────┐  │
│   │   Раскрыть   │ │   Позже   │  │
│   └──────────────┘ └───────────┘  │
│                                   │
╰───────────────────────────────────╯
```

| Действие | Результат |
|----------|-----------|
| Оба → Раскрыть | Геоглиф в шапке заменяется на фото (blur → чёткость, 1 сек) |
| Один → Позже | Ничего не меняется, попап закрывается у обоих |
| Оба → Позже | То же самое |

Если раскрытие произошло — имя в шапке становится настоящим, геоглиф → фото. Таймер продолжает идти.

---

### На 15-й минуте — конец сессии

Таймер достигает 00:00. Поле ввода блокируется. Последнее сообщение можно дочитать.

Снизу всплывает финальная карточка:

```
╭───────────────────────────────────╮
│                                   │
│   Время вышло                     │
│                                   │
│   Добавить друг друга в друзья?   │
│                                   │
│   ┌──────────────┐ ┌───────────┐  │
│   │   Добавить   │ │    Нет    │  │
│   └──────────────┘ └───────────┘  │
│                                   │
╰───────────────────────────────────╯
```

| Действие | Результат |
|----------|-----------|
| Оба → Добавить | Чат переходит в раздел Друзей на центральном экране. Переписка продолжается без ограничений |
| Один или оба → Нет | Чат закрывается. На левом экране снова появляется домик с кнопкой «Найти кого-то» |

## Полный флоу сессии

```
Свайп влево → Зал ожидания
    │
    ├─ Нажать «Найти кого-то» → в очереди
    │    Домик наполняется силуэтами
    │
    ▼
Матч найден (60 сек на подтверждение)
    │
    ├─ «Войти» → белая вспышка → Активный чат (тот же экран)
    │    На центральном экране появляется закреплённая карточка
    │
    ▼
⏱ 15:00 → 10:00
    │
    ├─ Попап: «Раскрыть личность и фото?»
    │    Оба «Раскрыть» → фото проявляется
    │    Кто-то «Позже» → попап закрывается, фото не раскрыто
    │
    ▼
⏱ 00:00 — сессия завершена
    │
    ├─ Карточка: «Добавить в друзья?»
    │    Оба «Добавить» → чат переходит в друзья, переписка продолжается
    │    Кто-то «Нет» → чат закрывается
    │
    ▼
Свайп влево снова показывает домик — готов к новому поиску
```
