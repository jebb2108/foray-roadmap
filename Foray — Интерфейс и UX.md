# Foray — Интерфейс и UX

← [[🗺️ Foray — Карта проекта]]

---

## Концепция

Foray — русское "foray" намекает, но название восходит к латинскому: **червоточина** как метафора. Незнакомые люди, разделённые пространством интересов, находят друг друга через алгоритм — как через wormhole. Дизайн это отражает: тёмный космос, минимум элементов, одна точка притяжения.

**Три правила дизайна:**
- Ничего лишнего на экране
- Тёмная тема, никогда светлой
- Анимации говорят, текст молчит там, где это возможно

### Типографика

Inter (или SF Pro на iOS / Roboto на Android). Только два размера на экран — крупнее просить не надо.

### Аватар по умолчанию

Генерируется по `user_id` — уникальный для каждого, но абстрактный: геометрический глиф космической темы (планета, созвездие, сигнал). Не показывает лицо. **Своё реальное фото видит только сам пользователь и те, кому оно раскрыто.**

### Фоновые частицы

На всех экранах — тонкое поле из мелких точек (`opacity: 0.15–0.25`), медленно дрейфуют. Почти незаметно, но создаёт ощущение пространства. Не мешает контенту.

## Навигация

```
                   ┌─────────┐
Зал ожидания ────►    Чаты     ◄────►  Профиль
                   └─────────┘
   свайп вправо      центр       свайп влево
```

Три экрана, горизонтальный свайп. Внизу три точки-индикатора — единственный навигационный элемент. Никакого tab bar, никаких иконок снизу.

Переход между экранами — лёгкий parallax: фоновые частицы движутся медленнее контента, создавая глубину.

---

## Экран: Чаты (центральный)

Открывается при запуске для авторизованного пользователя.

```
┌───────────────────────────────────┐
│  Foray                    ···     │  ← название + иконка настроек (только там)
├───────────────────────────────────┤
│                                   │
│  ┌─────────────────────────────┐  │
│  │  ⬡    @nickname             │  │  ← аватар: геоглиф (не раскрыт)
│  │        Привет, как дела?    │  │    жирный никнейм = непрочитано
│  │                     14:23 ● │  │    ● = непрочитанное (акцент)
│  └─────────────────────────────┘  │
│                                   │
│  ┌─────────────────────────────┐  │
│  │  [фото]  @friend_name       │  │  ← раскрытый аватар (друг)
│  │          хорошо, ты?        │  │
│  │                      вчера  │  │
│  └─────────────────────────────┘  │
│                                   │
│                                   │
│                                   │
│  ┌─────────────────────────────┐  │
│  │  ○     @unknown             │  │  ← завершённая сессия
│  │        Сессия завершена     │  │    аватар — пустой круг
│  │                  3 дня назад│  │    серый текст
│  └─────────────────────────────┘  │
│                                   │
│            ·  ●  ·               │  ← индикатор экрана
└───────────────────────────────────┘
```

**Детали:**
- Чаты создаются **только** через матчмейкинг — кнопки «новый чат» нет
- Активные чаты (сессия не завершена) — сверху
- Завершённые — в секции «архив», read-only, без поля ввода
- Аватар партнёра: раскрытый → фото; не раскрытый → уникальный геоглиф
- Свайп по чату вправо → архивировать / удалить

## Экран: Зал ожидания (свайп влево)

Центральный элемент — маленький сюрреалистичный домик: физический, слегка ненастоящий, как будто из другого масштаба. Большие окна, внутри — диваны. За окнами мерцают полупрозрачные силуэты людей, которые живут своей жизнью и не замечают нас. Их количество отражает размер очереди.

Фон экрана — тёмный, почти чёрный. Домик расположен в центре, немного ниже середины. Никаких других элементов окружения — просто домик в пустоте.

### Состояние 2 — В очереди (домик с людьми)

Силуэты появляются постепенно по мере роста очереди. Максимум — 5–6 фигур, после этого они просто становятся чуть плотнее. Силуэты очень блеклые (`opacity: 0.15–0.25`), едва различимы — как будто люди за матовым стеклом световые годы отсюда. Они медленно двигаются: кто-то сидит и не шевелится, кто-то прохаживается, кто-то как будто разговаривает с другим. Движения случайные, петляющие, никогда не смотрят в сторону наблюдателя.

```
┌───────────────────────────────────┐
│                                   │
│                                   │
│          ╱▔▔▔▔▔▔▔▔▔▔▔╲           │
│         ▕             ▏           │
│         ├──────────────┤          │
│         │ ┌────┐ ┌────┐│          │
│         │ │░╻ ░│ │░╻╻░││          │  ← силуэты за стеклом
│         │ │░╽ ░│ │░╽╽░││          │    блеклые, мерцают
│         │ └────┘ └────┘│          │
│         │    ┌────┐    │          │
│         │    │ ██ │    │          │  ← дверь закрыта
│         └────┴────┴────┘          │
│                                   │
│          Ищем... 4 рядом          │
│                                   │
│   ┌───────────────────────────┐   │
│   │           Выйти            │   │
│   └───────────────────────────┘   │
└───────────────────────────────────┘
```

**Детали силуэтов:**
- Анимация мерцания: случайный `opacity` между 0.10 и 0.30, медленно
- Каждый силуэт — автономный: петлевая анимация перемещения по своей траектории
- Они не реагируют на нажатия, на время, на пользователя
- За одним окном — диван, за другим — пространство для ходьбы

---

### Состояние 3 — Матч найден

Все силуэты медленно гаснут — `opacity` к нулю за 1.5 секунды. Окна темнеют. Домик на секунду замирает совершенно пустым и тихим.

Потом дверь открывается.

Из дверного проёма — белое сияние. Не анимированное, не пульсирующее. Просто ровный, тихий, очень яркий свет. Контраст с тёмным домиком и тёмным фоном делает его значимым.

```
┌───────────────────────────────────┐
│                                   │
│                                   │
│          ╱▔▔▔▔▔▔▔▔▔▔▔╲           │
│         ▕             ▏           │
│         ├──────────────┤          │
│         │ ┌────┐ ┌────┐│          │
│         │ │    │ │    ││          │  ← окна тёмные
│         │ │    │ │    ││          │    никого нет
│         │ └────┘ └────┘│          │
│         │   ┌──────┐   │          │
│   ░░░░░░│░░░│██████│░░░│░░░░░░    │  ← дверь открыта
│   ░░░░░ │   │      │   │ ░░░░░    │    белый свет наружу
│         └───┴──────┴───┘          │    рассеивается на землю
│                                   │
│                                   │
│   ┌──────────────────────────┐    │
│   │  Интересы: музыка, кино  │    │  ← карточка всплывает снизу
│   └──────────────────────────┘    │
│   ╔══════════╗  ╔════════════╗    │
│   ║   Войти   ║  ║ Пропустить ║   │
│   ╚══════════╝  ╚════════════╝    │
│              ⏱ 0:52              │
└───────────────────────────────────┘
```

**Детали момента:**
- Пауза ~1 сек между исчезновением силуэтов и открытием двери — тишина важна
- Свет не мигает, не пульсирует — просто есть. Это единственное приглашение
- Карточка с интересами партнёра появляется снизу через bottom sheet — имя и фото скрыты
- Кнопка «Войти» — нажатие на неё запускает zoom forward через дверной проём, белая вспышка → чат
- «Пропустить» или таймер истёк → дверь медленно закрывается, силуэты возвращаются, поиск продолжается
- Если партнёр пропустил — дверь закрывается, краткое уведомление: «Не ответили — ищем дальше»

## Экран: Чат (открывается из списка)

### Активная сессия — до раскрытия

```
┌───────────────────────────────────┐
│  ←   ⬡  @unknown       ● онлайн  │  ← геоглиф вместо фото
│       Интересы: музыка, IT        │    интересы под именем
├───────────────────────────────────┤
│                                   │
│                   Привет!  14:01  │
│                              ✓✓   │
│                                   │
│  Привет) как дела?         14:01  │
│  ✓✓                               │
│                                   │
│               Неплохо, ты?  14:02 │
│                              ✓✓   │
│                                   │
│                                   │
│  ✏ печатает...                    │
│                                   │
├───────────────────────────────────┤
│  Сообщение...              [ ➤ ] │  ← только текст
└───────────────────────────────────┘  никакой скрепки, камеры, медиа
```

**Принципиально нет:**
- Вложений, изображений, видео, голосовых
- Стикеров и эмодзи-реакций (только текстовые эмодзи в сообщениях)
- Кнопки «переслать»

**Есть:**
- Долгое нажатие на сообщение → «Удалить» (только своё)
- ✓✓ — доставлено / прочитано

### Момент раскрытия (через 15 минут)

Bottom sheet, появляется у обоих одновременно. Фоновый чат не блокируется — можно продолжать печатать.

```
╭───────────────────────────────────╮
│                                   │
│      ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~        │  ← шиммер, космическая волна
│                                   │
│   Вы разговариваете уже 15 минут  │
│                                   │
│   Хотите узнать, кто перед вами?  │
│                                   │
│   ┌──────────────┐ ┌───────────┐  │
│   │   Раскрыть   │ │   Позже   │  │
│   └──────────────┘ └───────────┘  │
│                                   │
╰───────────────────────────────────╯
```

**Логика:**

| Действие | Результат |
|----------|-----------|
| Оба → Раскрыть | Аватары проявляются (blur → чёткость, 1 сек анимация) |
| Один → Раскрыть, второй → Позже | Ничего не происходит. Через +15 мин — повтор |
| Оба → Позже | Через +15 мин — повтор |
| Раскрытие произошло | Появляется кнопка «Добавить в друзья» в шапке чата |

После раскрытия геоглиф в шапке чата заменяется на фото партнёра.

---

### Завершённая сессия

```
┌───────────────────────────────────┐
│  ←   [фото / ⬡]  @unknown        │  ← фото если раскрыто, геоглиф если нет
│       Сессия завершена             │
├───────────────────────────────────┤
│                                   │
│   ... история переписки ...       │
│                                   │
│  ─────── сессия завершена ─────── │
│                                   │
│  ╭───────────────────────────╮    │
│  │  Добавить друг друга?     │    │  ← показывается один раз
│  │  [ Добавить ]  [ Позже ]  │    │    если ещё не добавлены
│  ╰───────────────────────────╯    │
│                                   │
└───────────────────────────────────┘
```

Поле ввода скрыто. Чат read-only.
«Добавить» → взаимный запрос → если оба приняли, чат переходит в «активные друзья» — можно писать снова в любой момент, без матчмейкинга.

## Флоу раскрытия профиля — полная схема

```
Начало чата
    │
    │  [таймер 15 мин]
    ▼
Popup: «Раскрыть?»
    │
    ├─ Оба → Раскрыть
    │        └─→ Аватары видны
    │             └─→ Кнопка «Добавить» в шапке
    │
    ├─ Хотя бы один → Позже
    │        └─→ Таймер снова 15 мин
    │             └─→ Popup повторяется
    │
    └─ Сессия завершается без раскрытия
             └─→ Popup «Добавить?» в архиве
                  ├─ Оба приняли → аватар раскрыт, чат активен
                  └─ Нет → остаётся геоглиф, чат в архиве
```
