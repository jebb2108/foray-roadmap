# Foray — Интерфейс и UX

← [[🗺️ Foray — Карта проекта]]

---

## Концепция

Foray — название восходит к латинскому: **червоточина** как метафора. Незнакомые люди, разделённые психологическим и географическим пространством, находят друг друга через алгоритм — разрыв барьеров. Дизайн это отражает: далекий космос, минимум элементов, одна точка притяжения.

**Три правила дизайна:**
- Ничего лишнего на экране
- Тёмная тема, никогда светлой
- Анимации говорят, текст молчит там, где это возможно

### Типографика

Inter (или SF Pro на iOS / Roboto на Android). Только два размера на экран — крупнее просить не надо.

### Аватар по умолчанию

Генерируется по `user_id` — уникальный для каждого, но абстрактный: геометрический глиф космической темы (планета, созвездие, сигнал). Не показывает лицо. **Своё реальное фото видит только сам пользователь и те, кому оно раскрыто.**

### Фоновые частицы

На всех экранах — тонкое поле из мелких точек (`opacity: 0.15–0.25`), медленно дрейфуют. Почти незаметно, но создаёт ощущение пространства. Не мешает контенту.

## Навигация

```
   ┌─────────────────┐           ┌──────────────────────┐
   │ Зал ожидания    │◄──────────┤ Чаты с друзьями      ├────────► Профиль
   │ Активный чат    │   свайп   │ + Активный чат сверху│   свайп
   └─────────────────┘   вправо  └──────────────────────┘   влево
```

Три экрана, горизонтальный свайп. Внизу три точки-индикатора — единственный навигационный элемент. Никакого tab bar, никаких иконок снизу.

- **Свайп вправо** → Зал ожидания. Когда матч найден и подтверждён — этот же экран становится активным чатом
- **Центр** → Список друзей. Если идёт активная сессия — она закреплена сверху
- **Свайп влево** → Профиль

Переход между экранами — лёгкий parallax: фоновые частицы движутся медленнее контента, создавая глубину.

## Экран: Чаты с друзьями (центральный)

Открывается при запуске. Показывает только друзей — людей, с которыми был взаимный запрос после сессии. Если в данный момент идёт активная матч-сессия — она закреплена отдельной карточкой сверху.

```
┌───────────────────────────────────┐
│                                   │
│  ┌─────────────────────────────┐  │
│  │ ░ Активная сессия   ⏱ 11:42│  │  ← закреплённая карточка
│  │   Привет, как дела?         │  │    индиго-рамка, пульсирует
│  │                     → →     │  │    
│  └─────────────────────────────┘  │    
│                                   │
│  ─────────── Друзья ─────────── │
│                                   │
│  ┌─────────────────────────────┐  │
│  │  [фото]  @friend_name       │  │  ← только добавленные друзья
│  │          хорошо, ты?        │  │    фото всегда раскрыто
│  │                      вчера  │  │
│  └─────────────────────────────┘  │
│                                   │
│  ┌─────────────────────────────┐  │
│  │  [фото]  @another_friend    │  │
│  │          до завтра!         │  │
│  │                   3 дня     │  │
│  └─────────────────────────────┘  │
│                                   │
│            ·  ●  ·               │
└───────────────────────────────────┘
```

**Детали:**
- Здесь только друзья — переписка с ними свободная, без таймера
- Если активной сессии нет — закреплённой карточки нет, список начинается с друзей
- Сессии без взаимного добавления в друзья в этот список не попадают
- Нет кнопки «новый чат» — общение только через матчмейкинг или с уже добавленными друзьями

## Экран: Зал ожидания → Активный чат (свайп вправо)

Этот экран живёт в двух состояниях: **зал ожидания** (до матча) и **активный чат** (после подтверждения). Переход между ними происходит на месте — один и тот же экран, без переключения.

**Зал ожидания.** Центральный элемент — маленький сюрреалистичный домик: физический, слегка ненастоящий, как будто из другого масштаба. Большие окна, внутри — диваны. За окнами мерцают полупрозрачные силуэты людей, которые живут своей жизнью и не замечают нас. Над дверью — маленький числовой счётчик: точное количество людей в очереди прямо сейчас, обновляется в реальном времени.

Фон экрана — тёмный, почти чёрный. Домик расположен в центре, немного ниже середины. Никаких других элементов окружения — просто домик в пустоте.

---

### Состояние 1 — Не в очереди (пустой домик)

Никаких кнопок. Единственное взаимодействие — **нажатие на домик**.

```
┌───────────────────────────────────┐
│                                   │
│                                   │
│                                   │
│          ╱▔▔▔▔▔▔▔▔▔▔▔╲            │
│         ▕             ╲           │  ← крыша
│         ├──────────────┤          │
│         │ ┌────┐ ┌────┐│          │
│         │ │    │ │    ││          │  ← окна пустые, тёмные
│         │ │    │ │    ││          │
│         │ └────┘ └────┘│          │
│         │    ┌────┐    │          │
│         │    │    │    │          │  ← дверь закрыта; 
│         └────┴────┴────┘          │
│                                   │
│         Жми на комнату,           │
│       чтобы найти партнера        │  ← подпись под домиком
│                                   │
│             ●  ·  ·               │
└───────────────────────────────────┘
```

**Нажатие на домик** → вход в очередь. Силуэты за окнами появляются и становятся чуть ярче, чем обычно — сигнал что ты теперь часть этого пространства.

---

### Состояние 2 — В очереди (домик с людьми)

Силуэты за окнами теперь чуть чётче чем в состоянии 1 — ты вошёл, ты тоже здесь. Количество фигур растёт вместе с очередью (максимум 5–6, дальше просто становятся плотнее). Движения медленные, автономные — кто-то сидит, кто-то ходит, кто-то как будто разговаривает. Никто не смотрит наружу.

```
┌───────────────────────────────────┐
│                                   │
│                                   │
│          ╱▔▔▔▔▔▔▔▔▔▔▔╲            │
│         ▕             ╲           │
│         ├──────────────┤          │
│         │ ┌────┐ ┌────┐│          │
│         │ │░╻ ░│ │░╻╻░││          │  ← силуэты чуть чётче чем в
│         │ │░╽ ░│ │░╽╽░││          │    состоянии 1, медленно мерцают
│         │ └────┘ └────┘│          │
│         │    ┌────┐    │          │
│         │    │ ██ │    │          │  ← дверь закрыта; 
│         └────┴────┴────┘          │
│                                   │
│           Ты в очереди...         │  ← Индикатор состояния поиска партнера    
│                                   │
│       Будьте всегда вежливы       │  ← Различные советы для поддержания беседы
│                                   │
│             ●  ·  ·               │
└───────────────────────────────────┘
```

**Нажатие на домик** → выход из очереди. Силуэты за окнами тускнеют обратно до уровня состояния 1.

**Детали силуэтов:**
- В очереди: `opacity` 0.20–0.35 (чуть ярче чем вне очереди)
- Вне очереди: `opacity` 0.10–0.20
- Каждый силуэт — автономная петлевая анимация, не реагирует на пользователя
- За одним окном — диван, за другим — пространство для ходьбы
- Счётчик над дверью обновляется в реальном времени через WebSocket/polling

### Состояние 3 — Матч найден

Все силуэты медленно гаснут — `opacity` к нулю за 1.5 секунды. Окна темнеют. Домик на секунду замирает совершенно пустым и тихим.

Потом дверь открывается.

Из дверного проёма — белое сияние. Не анимированное, не пульсирующее. Просто ровный, тихий, очень яркий свет. Контраст с тёмным домиком и тёмным фоном делает его значимым.

```
┌───────────────────────────────────┐
│                                   │
│                                   │
│          ╱▔▔▔▔▔▔▔▔▔▔▔╲            │
│         ▕             ╲           │
│         ├──────────────┤          │
│         │ ┌────┐ ┌────┐│          │
│         │ │    │ │    ││          │  ← окна тёмные
│         │ │    │ │    ││          │    никого нет
│         │ └────┘ └────┘│          │
│         │   ┌──────┐   │          │
│   ░░░░░░│░░░│██████│░░░│░░░░░░    │  ← дверь открыта
│   ░░░░░ │   │      │   │ ░░░░░    │    белый свет наружу
│         └───┴──────┴───┘          │    рассеивается на землю
│                                   │
│           Партнер найден!         │
│                                   │
│                                   │  
│                                   │
│                                   │
│  ┌──────────────────────────┐     │
│  │ Жмите на комнату - войти │     │  ← всплывает подсказка
│  └──────────────────────────┘     │
└───────────────────────────────────┘
```

**Детали момента:**
- Пауза ~1 сек между исчезновением силуэтов и открытием двери — тишина важна
- Свет не мигает, не пульсирует — просто есть. Это единственное приглашение
- **Нажатие на домик** → zoom forward через дверной проём, белая вспышка → предвыборная комната
- Партнёр не нажал в течение 60 сек → дверь медленно закрывается, силуэты возвращаются
- Если партнёр отказался → дверь закрывается, подпись меняется на «Не ответили — ищем дальше»

---

### Состояние 4 — Предвыборная комната

Переход сюда: нажатие на домик когда дверь открыта → zoom через проём → белая вспышка → этот экран.

Воспроизводит логику старого проекта (chat.lllang.site) один в один, адаптировано под тёмную тему Foray. Три последовательных состояния одной панели.

#### 4a — Ожидание решения (60 сек)

```
┌───────────────────────────────────┐
│                                   │
│                                   │
│              ⬡                    │  ← геоглиф партнёра (синий цвет - парень)
│           @nickname, 23           │  ← никнейм + возраст (розовый - девушка)
│                                   │
│        музыка · IT · кино         │  ← интересы партнёра (chips)
│                                   │
│   «Люблю говорить о технологиях   │  ← intro-текст партнёра
│    и просто интересных людях»     │
│                                   │
│  ╔═══════════════════════════╗    │
│  ║   ✗       ⏱ 0:52      ✓   ║    │  ← панель: красная рамка
│  ╚═══════════════════════════╝    │    ✗ = отклонить  ✓ = подтвердить
│                                   │  ← 60-сек таймер под панелью
└───────────────────────────────────┘
```

#### 4b — Ты подтвердил, ждём партнёра

```
│  ╔═══════════════════════════╗    │
│  ║        [ отменить ]       │  ← янтарная рамка
│  ╚═══════════════════════════╝    │
```

Таймер скрыт. Кнопка «отменить» позволяет передумать.

#### 4c — Оба подтвердили

```
│  ╔═══════════════════════════╗    │
│  ║       Мэтч найден!        ║    │  ← зелёная рамка (#10B981)
│  ║          ⏱ 0:05           ║    │  ← 5-сек обратный отсчёт
│  ╚═══════════════════════════╝    │
```

Через 5 секунд — автоматический переход в активный чат.

Если истёк 60-секундный таймер в 4a или партнёр отказался → белая вспышка → домик снова, дверь закрывается.

---

### Состояние 5 — Активный чат (тот же экран)

После 5-секундного обратного отсчёта домик и предвыборная комната исчезают — экран становится чатом. Это всё ещё свайп вправо.

```
┌───────────────────────────────────┐
│  ⬡  @unknown          ⏱ 14:51    │  ← геоглиф + никнейм + таймер
├───────────────────────────────────┤
│                                   │
│                   Привет!  00:00  │
│                              ✓✓   │
│                                   │
│  Привет, как дела?         00:14  │
│  ✓✓                               │
│                                   │
│               Хорошо, ты?  00:31  │
│                              ✓✓   │
│                                   │
│  ✏ печатает...                    │
│                                   │
├───────────────────────────────────┤
│  Сообщение...              [ ➤ ] │
└───────────────────────────────────┘
```

**Таймер** (`⏱ 14:51`) — обратный отсчёт 15:00 → 00:00. За 2 минуты до конца становится акцентным (индиго).

**Только текст** — никаких вложений, камеры, медиа.

**На центральном экране** появляется закреплённая карточка с тем же таймером.

---

### На 10-й минуте — попап раскрытия

Появляется у обоих одновременно. Чат не блокируется, можно продолжать печатать поверх.

```
╭───────────────────────────────────╮
│                                   │
│      ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~        │  ← шиммер
│                                   │
│   Вы уже 10 минут разговариваете  │
│                                   │
│   Раскрыть личность и фото        │
│   друг друга?                     │
│                                   │
│   ┌──────────────┐ ┌───────────┐  │
│   │   Раскрыть   │ │   Позже   │  │
│   └──────────────┘ └───────────┘  │
│                                   │
╰───────────────────────────────────╯
```

| Действие | Результат |
|----------|-----------|
| Оба → Раскрыть | Геоглиф в шапке заменяется на фото (blur → чёткость, 1 сек) |
| Один → Позже | Ничего не меняется, попап закрывается у обоих |
| Оба → Позже | То же самое |

Если раскрытие произошло — имя в шапке становится настоящим, геоглиф → фото. Таймер продолжает идти.

---

### На 15-й минуте — конец сессии

Таймер достигает 00:00. Поле ввода блокируется. Последнее сообщение можно дочитать.

Всплывает финальная карточка:

```
╭───────────────────────────────────╮
│                                   │
│   Время вышло                     │
│                                   │
│   Добавить друг друга в друзья?   │
│                                   │
│   ┌──────────────┐ ┌───────────┐  │
│   │   Добавить   │ │    Нет    │  │
│   └──────────────┘ └───────────┘  │
│                                   │
╰───────────────────────────────────╯
```

| Действие           | Результат                                                                                   |
| ------------------ | ------------------------------------------------------------------------------------------- |
| Оба → Добавить     | Чат переходит в раздел Друзей на центральном экране. Переписка продолжается без ограничений |
| Один или оба → Нет | Чат закрывается. На левом экране снова появляется домик и все повторяется снова             |

## Экран: Профиль (свайп влево от центра)

Стандартный, без лишнего.

```
│          ╭───────────╮            │

│         │             │           │    при долгом нажатии
│          ╰───────────╯            │
│                                   │

│  │ музыка│ │  IT  │ │  кино    │  │  ← редактируемые теги
│  └───────┘ └──────┘ └──────────┘  │
│  + добавить                       │
│                                   │
│  О себе                           │
│  Пара слов о тебе...              │  ← опциональное поле
│                                   │
│  ───────────────────────────────  │
│                                   │
```

**Чего нет:**
- Телефон — не привязывается
- Социальные сети — нет
- Статистика — нет (чтобы не геймифицировать)
- Тёмная/светлая тема — только тёмная

## Чат с другом (из центрального экрана)

Открывается нажатием на друга в списке. Без таймера — переписка свободная.

```
┌───────────────────────────────────┐
│  ←  [фото]  @friend_name ●        │ ← индикатор онлайн / не онлайн
├───────────────────────────────────┤
│                                   │
│                   Привет!  14:01  │
│                               ✓✓  │
│                                   │
│  Привет, как ты? 14:02            │
│                     ✓✓            │
│                                   │
│  ✏ печатает...                    │
│                                   │
├───────────────────────────────────┤
│  Сообщение...              [ ➤ ] │
└───────────────────────────────────┘
```

Фото всегда раскрыто. Без таймера. Только текст — те же правила что и в сессионном чате.

## Полный флоу сессии

```
Свайп вправо → Зал ожидания (домик)
    │
```
