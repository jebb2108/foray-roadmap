# Foray — Обзор

← [[🗺️ Foray — Карта проекта]]

## Что такое Foray

Нативное мобильное приложение для парных разговорных сессий на английском языке. Самостоятельный продукт — не требует Telegram и не является Mini App.

## Что изменяется

| Аспект | Было | Станет |
|--------|------|--------|
| Идентификация | Telegram ID | Email / телефон + собственный аккаунт |
| Платформа | Web (Mini App) | iOS + Android (нативное) |
| Push уведомления | Нет | FCM + APNs (матч найден, сессия начинается) |
| Polling матчмейкинга | Каждую секунду | Push notification |
| Обмен контактами | Telegram | In-app запрос / телефон |
| Оплата | YooKassa (веб) | YooKassa + Apple Pay + Google Pay |

## Что добавляется

- **Настройки длительности сессии** (15 / 30 / 45 мин)
- **Рейтинг партнёра** после сессии
- **Сохранение слов из чата** — тап на слово → добавить в [[Словарь]]
- **Темы сессии** — фильтр по интересам при матчмейкинге
- **Onboarding** — встроенный в приложение

## Gateway

Существующий [[Gateway Сервис]] остаётся без изменений. Foray обращается к нему напрямую через новый мобильный API-слой.
