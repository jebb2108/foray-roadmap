## Что такое Foray

Нативное мобильное приложение для парных разговорных сессий на основе общих интересов. Самостоятельный продукт с собственной системой аккаунтов.

| Email верификация | Перенести | [[Foray — Аутентификация]] |

## Что изменяется

| Аспект | Было | Станет |
|--------|------|--------|
| Идентификация | Веб-сессия | Email + пароль + собственный аккаунт |
| Платформа | Web | iOS + Android (нативное) |
| Push уведомления | Нет | FCM + APNs (матч найден, сессия начинается) |
| Polling матчмейкинга | Каждую секунду | Push notification |
| Обмен контактами | Веб-форма | In-app запрос дружбы |
| Оплата | YooKassa (веб) | YooKassa + Apple Pay + Google Pay |

## Что добавляется

- **Рейтинг партнёра** после сессии
- **Темы сессии** — фильтр по интересам при матчмейкинге
- **Onboarding** — встроенный в приложение

## Gateway

Существующий [[Gateway Сервис]] остаётся без изменений. Foray обращается к нему напрямую через новый мобильный API-слой.
